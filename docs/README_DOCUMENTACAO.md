# Documentação do EnergiaIOT

Esta pasta reúne a documentação da proposta de evolução do projeto EnergiaIOT para a N3.

## Arquivo principal
- `EnergiaIOT_CP12_Projeto_v1_1.pdf`: documento de projeto, arquitetura, requisitos R1–R18, proposta de hardware, contrato MQTT inicial, tecnologias, cronograma e pendências.

## Diagramas
Os diagramas em `diagramas/` ilustram a arquitetura, fluxo de dados, fluxo de comandos e fluxo do firmware.

## Importante
Este documento registra a proposta e o planejamento. Requisitos descritos como planejados ou pendentes não devem ser considerados implementados até que exista código, teste e evidência correspondente.
